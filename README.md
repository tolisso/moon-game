# Moon Courier Crisis

Прототип логистической стратегии в реальном времени, где игровое поле — поверхность
планеты-шара. Godot 4 / GDScript со статической типизацией.

## Запуск

Собрано и проверено на Godot 4.5.1 stable (без C#, дополнительных зависимостей нет).

1. Открыть Godot, `Import` → выбрать `project.godot` в этой папке.
2. Нажать F5 (главная сцена — `scenes/main.tscn`).

## Геймплей

На северном полюсе планеты расположена база. У нас есть три ровера у которые должны доставлять заказы по планете.

Мы контролируем сложность: чем выше сложность тем более тяжелые и далекие заказы появляются. Чем тяжелее и дальше заказ тем он приносит больше денег.

Чтобы успешно доставлять заказы мы должны прокачивать запас энергии и максимальный переносимый вес роверов.

На поверхности планеты есть кратеры, скорость роверов в них уменьшается в двое, но расход энергии остается на том же уровне - это зоны которые мешают доставке.

У игрока есть полторы минуты чтобы заработать столько золота сколько он может.

Игру можно сохранить или загрузить (для хранения используется SQLite).
