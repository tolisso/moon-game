# Sphere RTS (MVP)

Прототип логистической стратегии в реальном времени, где игровое поле — поверхность
планеты-шара. Godot 4 / GDScript со статической типизацией.

## Запуск

Собрано и проверено на Godot 4.5.1 stable (без C#, дополнительных зависимостей нет).

1. Открыть Godot, `Import` → выбрать `project.godot` в этой папке.
2. Нажать F5 (главная сцена — `scenes/main.tscn`).

## Как играть

На карте постоянно есть только база. В случайных точках планеты появляются заказы —
оранжевые кружки, размер кружка пропорционален требуемому грузу.

1. Клик по заказу открывает окно со всем парком роверов. Видно грузоподъёмность,
   текущую/максимальную энергию, скорость (порожняком → с этим грузом), время
   рейса туда-обратно. Ровер, который не проходит по лимитам, показан серым с
   причиной: «занят», «мало грузоподъёмности», «мало энергии».
2. Кнопка «Отправить» — ровер выезжает с базы, едет по кратчайшей дуге к точке,
   сдаёт груз и возвращается. Всё это время он занят и недоступен для других
   заказов, а вернувшись на базу — снова исчезает с карты.
3. За доставку платят золотом (зависит от дистанции). Клик по базе открывает окно
   прокачки: у каждого ровера можно поднять скорость, энергию, грузоподъёмность и
   силу.

| Действие | Ввод |
| --- | --- |
| Вращение планеты по долготе | `←` / `→` |
| Наклон (к полюсам, до ±85°) | `↑` / `↓` |
| Зум камеры | Колесо мыши |
| Окно заказа | ЛКМ по кружку заказа |
| Окно прокачки | ЛКМ по базе |
| Закрыть окно | `Esc`, ПКМ или клик вне окна |

## Характеристики роверов

Трое роверов получают случайные стартовые характеристики (диапазоны — в
`balance.gd`):

- **Базовая скорость** — °/сек по дуге, порожняком.
- **Энергия** — тратится 1 единица на градус дуги, то есть энергия и есть запас
  хода в градусах. Проверка при отправке: `энергия ≥ 2 × дистанция`. На базе
  заряжается со скоростью `RECHARGE_PER_SEC`, поэтому сразу после рейса ровер
  может не проходить по лимиту для дальнего заказа.
- **Максимальный груз** — сколько тонн он вообще может взять.
- **Сила** — при силе `S` каждые `S` единиц груза уменьшают скорость вдвое:
  `скорость = базовая × 0.5^(груз / сила)`. Обратно ровер едет порожняком, на
  полной скорости, поэтому время рейса считается по двум участкам отдельно.

Над выехавшим ровером две полоски: синяя — энергия, оранжевая — груз (видна
только на пути к точке).

## Где крутить баланс

Все игровые числа собраны в `scripts/balance.gd`, менять только там:

| Что | Константы |
| --- | --- |
| Размер парка | `ROVER_COUNT` |
| Стартовые характеристики | `START_SPEED_*`, `START_ENERGY_*`, `START_CARGO_*`, `START_STRENGTH_*` |
| Расход и зарядка энергии | `ENERGY_PER_DEG`, `RECHARGE_PER_SEC` |
| Цены прокачки (рост ×1.5) | `UPGRADE_COST_GROWTH`, `*_UPGRADE_BASE_COST` |
| Прибавка за улучшение (линейно) | `*_UPGRADE_STEP` |
| Поток заказов | `MAX_ORDERS`, `START_ORDERS`, `ORDER_INTERVAL_MIN/MAX` |
| Дальность заказов | `ORDER_MIN_DISTANCE_DEG`, `ORDER_MAX_DISTANCE_DEG`, `ORDER_REACH_MARGIN` |
| Рост требуемого груза со временем | `ORDER_CARGO_START`, `ORDER_CARGO_GROWTH_PER_SEC`, `ORDER_CARGO_JITTER` |
| Награда за доставку | `START_GOLD`, `REWARD_BASE`, `REWARD_PER_DEG`, `REWARD_PER_CARGO` |
| Формулы (штраф за груз, цена, награда, рост груза) | статические функции в конце `balance.gd` |

Небалансовые вещи лежат отдельно: камера и вращение — константы в `world.gd`,
размеры маркеров и полосок — в `delivery_order.gd`, `rover.gd`, `base_station.gd`,
внешний вид окон — в `ui_kit.gd`.

Ограничители, о которых стоит знать: требуемый груз никогда не превышает
грузоподъёмность лучшего ровера, а дистанция заказа — запас хода лучшей батареи
(`ORDER_REACH_MARGIN`), иначе на карте зависали бы невыполнимые заказы.

## Координаты

Позиция — это `GeoCoord` (широта, долгота в градусах, `float`). На вход
принимаются любые значения, включая диапазон 0..360; внутри они сворачиваются в
канонический вид: широта `[-90, 90]`, долгота `[0, 360)`. Переход через полюс
переворачивает полушарие и сдвигает долготу на 180°, как и на реальном шаре.

Соглашение об осях: `+Y` — северный полюс, долгота 0 смотрит в `+X` и растёт в
сторону `+Z`.

## Структура

| Файл | Назначение |
| --- | --- |
| `scripts/balance.gd` | Все игровые числа и формулы в одном месте |
| `scripts/geo_coord.gd` | Координата на сфере, нормализация, расстояние |
| `scripts/geo.gd` | Математика: гео ↔ вектор, дуги, пересечение луча со сферой |
| `scripts/sphere_shapes.gd` | Плоские маркеры на сфере: заливка круга и кольцо |
| `scripts/base_station.gd` | База: площадка и территория |
| `scripts/delivery_order.gd` | Заказ: точка, объём груза, маркер, статус |
| `scripts/rover.gd` | Ровер: характеристики, энергия, поездка туда-обратно |
| `scripts/path_view.gd` | Лента маршрута и маркер цели |
| `scripts/graticule.gd` | Сетка меридианов и параллелей |
| `scripts/ui_kit.gd` | Общие элементы окон: панель, строки, кнопки |
| `scripts/mission_dialog.gd` | Окно выбора ровера под заказ |
| `scripts/upgrade_dialog.gd` | Окно прокачки на базе |
| `scripts/world.gd` | Корень игры: вращение, заказы, пикинг, отправка, золото |

Клик превращается в точку через пересечение луча камеры со сферой, поэтому
обратная сторона планеты недоступна для кликов, а маркеры, роверы и ленты
маршрутов за горизонтом отсекаются самой сферой по глубине.
