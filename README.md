# Sphere RTS (MVP)

Прототип стратегии в реальном времени, где игровое поле — поверхность планеты-шара.
Godot 4 / GDScript со статической типизацией.

## Запуск

Собрано и проверено на Godot 4.5.1 stable (без C#, дополнительных зависимостей нет).

1. Открыть Godot, `Import` → выбрать `project.godot` в этой папке.
2. Нажать F5 (главная сцена — `scenes/main.tscn`).

Если установлена другая минорная версия 4.x, при импорте Godot предложит
обновить `config/features` в `project.godot` — это безопасно.

## Управление

| Действие | Ввод |
| --- | --- |
| Вращение планеты по долготе | `←` / `→` |
| Наклон (к полюсам, до ±85°) | `↑` / `↓` |
| Зум камеры | Колесо мыши |
| Выбрать ровер | ЛКМ по кубику |
| Приказ ехать | ЛКМ по поверхности при выбранном ровере |
| Снять выбор | ПКМ |

Ровер едет по кратчайшей дуге большого круга с постоянной угловой скоростью
(`Rover.ANGULAR_SPEED_DEG`, 22°/сек). Оставшийся путь рисуется лентой по
поверхности, конечная точка — ромбовидным маркером.

## Координаты

Позиция — это `GeoCoord` (широта, долгота в градусах, `float`). На вход
принимаются любые значения, включая диапазон 0..360; внутри они сворачиваются в
канонический вид: широта `[-90, 90]`, долгота `[0, 360)`. Переход через полюс
переворачивает полушарие и сдвигает долготу на 180°, как и на реальном шаре.

Соглашение об осях: `+Y` — северный полюс, долгота 0 смотрит в `+X` и растёт в
сторону `+Z`.

## Структура

| Файл | Назначение |
| --- | --- |
| `scripts/geo_coord.gd` | Координата на сфере, нормализация, расстояние |
| `scripts/geo.gd` | Математика: гео ↔ вектор, дуги, пересечение луча со сферой |
| `scripts/rover.gd` | Юнит: состояние движения по дуге, визуал квадратика |
| `scripts/path_view.gd` | Лента маршрута и маркер цели |
| `scripts/graticule.gd` | Сетка меридианов и параллелей |
| `scripts/world.gd` | Корень игры: вращение, пикинг, приказы, HUD |

Выбор и приказы работают целиком в сферических координатах: клик
превращается в точку через пересечение луча камеры со сферой, поэтому обратная
сторона планеты недоступна для кликов, а лента маршрута и роверы за горизонтом
отсекаются самой сферой по глубине.
